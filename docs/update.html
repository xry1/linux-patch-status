如何更新这份归档

这是发布到 GitHub Pages 的静态邮件归档。首页显示数据更新时间，访客可以直接阅读已收录的完整邮件。新回复会在维护者发布新版后显示。

站点维护者的更新流程

  1. 在 Lore 搜索结果页下载 full threads 的 mbox.gz。
  2. 在本地工作台导入归档，等待合并完成。
  3. 运行仓库中的 发布网站.cmd，将最新报告推送到 GitHub。
  4. 等待仓库的 Pages 部署完成，然后刷新网站。

也可以将归档拖到发布脚本上，直接合并进已有站点数据。完整命令和首次配置方法见仓库 README。

阅读与状态

点击 Thread messages 在本页归档中阅读回复，无需访问 Lore。状态是邮件信号的归纳，核对是否已合入时请查看目标版本、分支和最新回复。

本网站不会在后台自动抓取 Lore；网站中没有上传入口。遇到 Lore 验证时，由下载归档的人在浏览器处理。
